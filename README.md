# Spin ID — demo

A static demo of **Spin ID**, a pitcher-identification app built from release and spin: every MLB pitcher's
Spin ID (slot, spin efficiency, tilt offset, and spin for the speed), families, comps, Potential, What-If,
one-page reports, and a validation Lab with pre-registered tests (failures included).

**Open the demo:** https://kfili48.github.io/spin-id-demo/

- 55 showcase pitcher-seasons across all 15 families, plus the Lab's case studies, precomputed.
- What-If here uses a precomputed grid (slot −15° to +15°, efficiency −10 to +10 points, in steps of 5).
- No raw pitch-level data and no amateur data.

Data: MLB Statcast via Baseball Savant. Stuff+ is Spin ID's own model, not FanGraphs Stuff+.
